# Student Grade Tracker

A Java-based console application developed as part of my CodeAlpha Internship. It helps manage student records by storing marks, calculating total and average scores, and identifying the highest and lowest marks.

## Features

- Add student details
- Enter subject marks
- Calculate total and average
- Find highest and lowest marks
- Display student records

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- Arrays & ArrayList
- Scanner Class

## How to Run

```bash
javac StudentGradeTracker.java
java StudentGradeTracker
```
